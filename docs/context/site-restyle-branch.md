가이드 사이트 재입힘 작업은 **본 폴더가 아니라 `site-restyle` 가지/별도 폴더**에서 한다. 본 사이트는 손대지 않은 상태다.

검수 화면 두 장을 로컬 서버로 띄워 보는 구조다 — 저장소 뿌리에서 정적 서버를 열고 `pages/_restyle-test/home.html`(홈 재입힘 예상)과 `pages/_restyle-test/parts.html`(승격 후보 검수)을 연다. 두 화면 모두 CSS·JS 링크에 버전 표시가 붙어 있어 새로고침만으로 최신을 읽는다 — 토큰 이름이 바뀐 뒤 옛 CSS 를 물고 있어 선이 사라져 보인 사고 때문에 넣었다.

**river 가 확정한 것**(다시 묻지 말 것): 뱃지는 파랑=승인/확인·빨강=주의/에러 두 색만 · 구분선 세로 높이는 크기 축이 아님(간격 값으로 둠) · LNB 가로는 240·280 둘 다 제공 · LNB 는 세 벌(로고✕구분명✕ / 로고✕구분명○ / 로고○구분명✕)만 · 접힘 표시는 우측 상단 아이콘 하나로만 · 로고에 집 아이콘 없음 · 사이드바 선택 상태에 배경 없음 · 접힘 아이콘은 옆 메뉴 아이콘과 같은 크기(선 굵기가 같아지는 쪽 우선).

**남은 결정**: 뱃지 채움 배경·청록/주황/초록의 semantic 이름 신설 여부 · 어두운 화면에서 하위메뉴가 부모보다 밝아 보이는 문제(어두운 판은 색 단계가 반대) · 새 아이콘 `ic_패널접기` 의 Figma 라이브러리 등록 · 로고의 어두운 화면용 판.
