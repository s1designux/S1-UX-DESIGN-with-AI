배포본 아이콘은 CSS 마스크로 그려서, 화면을 **파일로 직접 열어 찍으면 아이콘 자리가 빈다.** 부품이 깨진 것처럼 보이지만 실제로는 멀쩡하다.

**Why:** 2026-09-18 패턴 시안 검증에서 뒤로가기 화살표가 안 보여 부품 결함으로 오인할 뻔했다. 같은 화면을 로컬 서버 주소로 띄우니 정상이었다.

**How to apply:** 아이콘이 들어간 화면은 스크린샷만 믿지 말고 로컬 서버(4173) 주소로 한 번 더 본다. 작업 폴더의 파일도 그 서버가 같이 서빙한다. 관련: [[pattern-builder-progress]]
