# LNB 접힌 띠 잠깐 펼침 — 승인 (2026-10-21)

river 승인: "오케이 현재 안으로 승인할게. 정본에 반영후에 관련된 컴포넌트 안내쪽 html/css까지만 내용 반영해줘. 개발툴별 라이브러리는 추후에 업데이트할게"

- 접힌 띠에서 메뉴 칸(고른 칸 포함)에 마우스를 올리면 즉시 펼친 모습을 잠깐 보여 준다. 하위메뉴 칸이면 그 하위메뉴도 연다. 마우스가 판을 떠나거나 Esc·판 밖 초점이면 다시 접힌다.
- 펼치는 순간 선택 칸의 파란 바탕은 바로 없앤다. 폭·칸 높이·아이콘·글자 크기만 .24s cubic-bezier(.35,0,.15,1) 로 이어 바꾼다. 글자를 투명에서 띄우지 않는다(빈 흰 판이 보였다).
- 메뉴(a)를 누르면 선택(aria-current)이 옮겨진다. 하위메뉴를 고른 채 접히면 상위 칸이 선택 모양(파란 칸)이 된다 — Figma 정본에 따로 없는 표현이지만 접힘 Selected 모양을 그대로 쓴다.
- 반영 범위: 웹 배포본(ui-library lnb 0.4.0 · 배포본 0.27.0) + 디자인가이드 안내 화면. **개발툴별 라이브러리(React Native 등) 동작 이식은 추후** — river 지시 전까지 하지 않는다.
