**river 결정 2026-09-22 (GUI 검수기 = figma-vars-installer 의 audit 탭):**
1. 손으로 그린 도형·글자·아이콘에는 모양(크기·둥글기·글자 위치)으로 "버튼/입력칸"을 맞혀 부품 토큰을 걸지 않는다. 공통 역할 토큰(글자·면·테두리·아이콘)과 팔레트 색만 앞에, 색이 정확히 같을 때만 자동. 부품이면 **사람이 라이브러리 부품으로 직접 바꾼다** — 검수기는 "버튼처럼 보입니다 → 직접 바꾸세요"만 안내.
2. 부품 안 노드의 근거는 **라이브러리 부품**(remote 연결·정본 이름·레거시 표)뿐. 직접 만든 컴포넌트·컴포넌트로 묶은 화면은 근거가 아니다. 부품이 실제로 바인딩한 토큰 묶음(component-facts.json tokenBindings, 자기 것 → 물려받은 것)이 1순위, 가까운 부품부터 한 묶음씩(바깥 부품으로 안 샘).
3. 부품 교체 후보는 레거시 가이드로 만든 인스턴스만. 직접 만든 것은 "레거시 목록에 없는 부품 N개"로 이름만 보여 준다.
4. 레거시 보존 화면(모두앱 등)에서는 이 검수기를 쓰지 않는다.

**Why:** 모양 추정은 손그림 상대로 원리상 확실해질 수 없어 로그인 버튼을 입력칸으로 보는 식의 오판이 반복됐다. 파운데이션만 묶으면 다크모드가 안 뒤집히고, 역할까지 묶으면 뒤집힌다.

**How to apply:** 검수기 자동 연결 규칙을 손볼 때 guess(모양 추정)를 근거로 되돌리지 말 것. 부품 이름→토큰 대응표를 손으로 쓰지 말고 사실표(component-facts.json, Gate 9e 가 정본과 묶음)에서 읽을 것. 사실표가 낡으면 설치기 빌드와 검수 실행이 둘 다 멈추게 해 뒀다. 2026-09-23 main 에 합쳐졌고 원격에도 올라갔다. 관련: [[legacy-service-patterns-separate]] [[worktree-per-session]]
