# Mobile Login 상태 목록

현재 패턴은 10개 대표 화면 상태로 구성된다. 화면 수는 구현 산출물의 예시 수이며, 서비스 구현에서는 같은 의미의 상태를 중복 생성하지 않는다.

프레임 이름 체계는 `registry/governance/screen-naming-policy.json` 을 따른다. **숫자만 = 기본 흐름 · 숫자+알파벳 = 그 단계에서 갈라진 분기**다. 화면을 가리키는 고정 식별자는 이름이 아니라 **Figma 노드 ID** 다.

## 제거된 상태

| 상태 | 제거 이유 | 제거 시점 |
|---|---|---|
| 아이디 미입력 오류 | 빈칸은 로그인 버튼 비활성으로 제출을 막고, 입력창 안내 문구가 필요한 행동을 이미 설명함 | 2026-08-21 |
| 비밀번호 미입력 오류 | 같은 원칙으로 별도 제출 후 오류 화면이 필요하지 않음 | 2026-08-21 |
| 인증 후 재로그인 (구 `1562:15`) | 새로운 기기 분기의 종착 상태이나 화면 표현이 `1562:14`(입력 완료)와 동일해 별도 프레임을 유지할 근거가 없음. 분기 복귀는 프로토타입 연결로 표현한다 | 2026-08-25 |

## 패턴 범위 밖

- 로그아웃 확인
- 서비스 메뉴와 하단 탭 탐색
- 회원가입
- 아이디·비밀번호 찾기 상세 흐름
- 본인 인증 자체의 세부 단계
