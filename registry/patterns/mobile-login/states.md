# Mobile Login 상태 목록

현재 패턴은 11개 대표 화면 상태로 구성된다. 화면 수는 구현 산출물의 예시 수이며, 서비스 구현에서는 같은 의미의 상태를 중복 생성하지 않는다.

| 상태 | 목적 | 주요 표현 | Figma |
|---|---|---|---|
| 최초 진입 | 로그인 시작점 | 빈 입력 2개, 로그인 비활성 | `1562:3` |
| 입력 A | 아이디 편집 중 | 아이디 포커스, 비밀번호 빈칸, 로그인 비활성, 앱 키보드 | `1562:4` |
| 입력 B | 비밀번호 편집 중 | 아이디 입력 완료, 비밀번호 포커스·마스킹, 로그인 활성, 앱 키보드 | `1562:5` |
| 계정 불일치 | 서버 로그인 실패 | 두 입력창 오류 테두리, 비밀번호 아래 통합 오류 문구와 시도 횟수 | `1562:8` |
| 자동 로그인 질문 | 로그인 성공 후 설정 선택 | 성공 안내, 자동 로그인 여부, 취소·확인 | `1562:9` |
| 자동 로그인 완료 | 설정 결과 확인 | 자동 로그인 설정 완료, 확인 | `1562:10` |
| 새로운 기기 안내 | 본인 인증 필요 | 미인증 기기 안내, 기존 기기 영향 안내, 확인 | `1562:11` |
| 인증 완료 안내 | 재로그인 유도 | 인증 완료, 다시 로그인 안내, 확인 | `1562:12` |
| 기기 등록 질문 | 현재 기기 등록 동의 | 정보 보호 이유, 현재 기기 등록 여부, 취소·확인 | `1562:13` |
| 새로운 기기 기본 A | 추가 보안 분기의 배경 상태 | 입력 완료 로그인 화면 | `1562:14` |
| 새로운 기기 기본 B | 추가 보안 분기의 배경 상태 | 입력 완료 로그인 화면 | `1562:15` |

## 제거된 상태

| 상태 | 제거 이유 |
|---|---|
| 아이디 미입력 오류 | 빈칸은 로그인 버튼 비활성으로 제출을 막고, 입력창 안내 문구가 필요한 행동을 이미 설명함 |
| 비밀번호 미입력 오류 | 같은 원칙으로 별도 제출 후 오류 화면이 필요하지 않음 |

## 패턴 범위 밖

- 로그아웃 확인
- 서비스 메뉴와 하단 탭 탐색
- 회원가입
- 아이디·비밀번호 찾기 상세 흐름
- 본인 인증 자체의 세부 단계
