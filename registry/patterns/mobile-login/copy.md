# Mobile Login 현재 팝업 문구

이 문서는 `mobile-login` 패턴의 현재 Figma 팝업 문구를 제공한다. 서비스별 문구를 바꿀 때는 의미와 행동을 유지하고 `content-rules.md`를 함께 따른다.

## 자동 로그인 질문

- 타이틀: `자동 로그인 안내`
- 본문: `다음부터 자동으로 로그인할까요?`
- 버튼: `아니오` / `네`

## 자동 로그인 설정 완료

- 타이틀: `자동 로그인 설정 완료`
- 본문: `자동 로그인이 설정되었어요.`
- 버튼: `확인`

## 본인 인증 안내

- 타이틀: `본인 인증 안내`
- 본문: `서비스를 이용하려면 본인 인증을 진행해 주세요. 본인 인증 시 기존 기기는 인증이 해제돼요.`
- 버튼: `확인`

## 기기 인증 완료

- 타이틀: `기기 인증 완료`
- 본문: `사용 중인 기기로 인증이 완료됐어요.`<br>`다시 로그인해 주세요.`

- 버튼: `확인`

## 기기 등록 안내

- 타이틀: `기기 등록 안내`
- 본문: `에스원은 고객님의 소중한 정보를 보호하기 위해 인증 기기 등록 후 서비스를 제공하고 있어요.`<br>`현재 인증한 기기로 등록 후 로그인할까요?`

- 버튼: `아니오` / `네`

## 로그인 화면 보조 버튼

- 다른 로그인 수단: `휴대전화번호로 로그인` — **전 화면 동일**(가려진 배경 포함). 레거시 원본에 혼재하던 `휴대폰 번호로 로그인` 은 2026-08-25 에 정리했다.
