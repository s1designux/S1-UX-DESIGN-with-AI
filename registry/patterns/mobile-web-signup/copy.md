# Mobile Web Signup 현재 문구

## 약관

- 제목: `서비스 약관에 동의해 주세요`
- 전체: `전체 동의하기`
- 항목: `회원 약관 동의(필수)` / `개인정보 수집 및 이용 동의(필수)` / `만 14세 이상이에요(필수)`
- 행동: `본인 인증`

## 계정 입력

- 아이디 안내: `영어 소문자, 숫자를 조합하여 4~12자 입력해 주세요.`
- 비밀번호 안내: `영문, 숫자, 특수문자를 조합하여 8~15자로 입력해 주세요.`
- 비밀번호 확인: `비밀번호 확인` / `입력해 주세요`
- 이메일 도메인: `naver.com` / `kakao.com` / `gmail.com` / `nate.com` / `직접 입력`

이메일 화면에 `입력하신 이메일로 비밀번호를 찾을 수 있습니다.` 문구를 사용하지 않는다.

## 기존 회원·아이디

- 기존 회원: `이미 회원으로 가입되어 있습니다.` / `아이디 : abcdefg`
- 기존 아이디 제목: `기존 아이디를 사용하시겠어요?`
- 행동: `새 아이디 사용` / `아이디 선택`

## 완료

- 환영: `홍길동님, 환영합니다!`
- 안내: `서비스를 이용하시려면 앱을 설치해 주세요`
- 행동: `다음에 설치` / `앱 설치`
