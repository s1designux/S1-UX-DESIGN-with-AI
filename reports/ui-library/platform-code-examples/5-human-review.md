## 무엇을 봐 주시면 되나

1. **Mobile Components → 아무 컴포넌트 → 「개발 코드」** — 마크업이 Mobile 것인지
   (예: 버튼 `data-size="lg"`, 칩 `data-size="sm" data-break="mobile"`).
2. 코드 위 안내 한 줄이 도움이 되는지 —
   "Mobile 화면의 마크업입니다. PC 마크업은 PC Components 화면에서 확인하세요."
   (문구가 길거나 불필요하면 빼거나 줄일 수 있습니다.)
3. **PC Components** 쪽은 종전과 같은지.
