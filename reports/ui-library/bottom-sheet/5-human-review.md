## 승인 후 반영 — Text Button

river 가 "(A) 같이 뺀다"를 골랐다. Input(2026-09-07) → Button(2026-09-15) → Text Button 으로 **모바일 마우스오버 없음** 규칙이 세 부품에서 일관돼졌다.

- 크기 축이 없는 컴포넌트라 LG 로 가려낼 수 없어 **화면 구분 선언**으로 갈랐다(Input 과 같은 형태)
- 누름(`:active`) 밑줄은 어디서나 유지
- 이 과정에서 플랫폼 이식본 CSS 해석기가 `:not()` 안의 자손 선택자를 지원하지 않아 빌드가 멈췄다 → 해석기를 고쳤다(§15)
- 검사기도 함께 **강화**했다 — 종전 "밑줄이 있나" 한 줄에서 "누름은 어디서나 · 마우스오버는 PC 에서만"까지 못박았고, 적대 테스트로 막히는 것을 확인했다
