01 · 이번 업데이트

신규 정리된 컴포넌트

LNB (사이드바 메뉴)

__LNB_MINI__

왼쪽 세로 메뉴. 기본(로고 없음)·로고 얹음 두 벌, 가로 240·280, 접으면 80.

접힘카드 (Expandable Card)

__CARD_MINI__

제목 줄을 누르면 아래로 내용이 펼쳐지는 모바일 카드. 원본은 SW UX GUIDE V2.4.

구분선 (Divider)

__DIVIDER_MINI__

가로·세로 × 기본·굵게 × 옅은·진한. 목록 안에서는 글 줄에 맞춰 들여 씁니다.

뱃지 (Data Tag)

__TAG_MINI__

상태를 보여주기만 하는 라벨. 파랑 = 승인·확인, 빨강 = 주의·에러. 뱃지 전용 색 이름 7개를 새로 등록했습니다.

04 · 마치며

남은 논의와 AI로 나아진 점

추후 논의점

새 부품의 동작과 디자인은 실제 화면에서 함께 동작을 보면서 보완이 필요합니다.

AI 사용으로 나아진 점

부품을 한 번 만들어 두면, 쓰임별 화면과 동작·라이트/다크 차이를 AI가 바로 여러 벌 만들어 보여 줍니다. 보고 고르는 데 드는 시간이 크게 줄었습니다.

  • 부품 하나로 여러 패턴을 바로 — 접힘카드를 만든 뒤 신청 내역·출입 기록·공지 같은 쓰임별 화면을 자동으로 여러 벌 만들어 비교했습니다.
  • 동작·다크모드를 빠르게 보고 정리 — 접기·하위메뉴 같은 동작과 라이트·다크 대응을 한 화면에서 바로 바꿔 보며 확인하고 정리할 수 있었습니다.
