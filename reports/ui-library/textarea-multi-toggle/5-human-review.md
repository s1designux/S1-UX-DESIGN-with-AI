## 무엇이 바뀌었나

| | 전 | 후 |
|---|---|---|
| 긴글 입력칸 | 사이트에 손으로 쓴 코드 | 정본 기준 배포본 (상태 5종, 세로만 늘어남) |
| 분절 선택(Multi Toggle) | 사이트에 손으로 쓴 코드 | 정본 기준 배포본 (MD·SM, 화살표 키 이동) |
| 두 메뉴 | 회색으로 잠김 | 열림 |

## river 가 봐줄 것 (코드 아님)

1. 긴글 입력칸을 실제로 눌러 입력해 보고, 오른쪽 아래를 끌어 **세로로 늘어나는 느낌**이 적당한지
2. 분절 선택에서 **선택된 칸이 확실히 선택돼 보이는지** (라이트·다크 양쪽)
3. 안내 문장이 이해되는지 — 긴글 입력칸에는 이번에 **안내 문구가 없다**는 점이 헷갈리지 않는지
4. 상태 표(기본·마우스 올림·선택·비활성)가 실제 화면과 같아 보이는지

## 결정이 필요한 것

- **HD-1 — 독립 검증을 한 번 더 할까요?**
  분절 선택은 JavaScript 로 움직이는 부품이라(화살표 키 이동·선택 전환) 체크박스·라디오보다 잘못될 여지가 큽니다. 지금은 제가 실제 브라우저에서 눌러 보고 전부 정상임을 확인했습니다.
  (A) 이대로 승인 — 제 검증 결과로 충분 / (B) 검증 전담 에이전트를 한 번 더 돌린 뒤 승인
  안 정하면 (A) 로 두지 않고 **승인 대기 상태로 멈춰 있습니다.**

## 참고 — 이번에 만들지 않은 것

- 긴글 입력칸의 **안내·오류 문구**: 정본(Figma 설치기)에 아직 없어 이번 배포본에서 뺐습니다(river 결정). 정본에 먼저 추가한 뒤 다음 차례에 넣습니다.
- 라벨·글자수 세기·크기 종류: 정본에 없습니다.
- 분절 선택의 **모바일 크기**: 정본이 PC 전용입니다.
