## 직접 눌러보실 것 (검수 화면 위쪽 안내와 동일)
1. **Select** — 트리거를 눌러 목록을 열고, 화살표 키로 옮긴 뒤 `Enter`. 값이 트리거에 들어오고 닫힙니다. 바깥을 눌러도 닫힙니다.
2. **Dropdown** — 글자 유형과 체크박스 유형 두 가지입니다. 체크박스 유형에서 「전체 선택」을 눌러 보세요(전부 켜짐 ↔ 전부 꺼짐). 개별 옵션을 다 켜면 「전체 선택」이 스스로 켜집니다.
3. **Filter Chip** — 눌러서 열고(Selected), 값을 고르면 닫히며 값이 칩에 남습니다(Complete). `Esc` 로도 닫힙니다.
