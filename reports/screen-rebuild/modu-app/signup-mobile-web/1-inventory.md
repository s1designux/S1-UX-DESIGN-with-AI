## 🚨 원본 자체의 다른 이상 징후 (사실만 기록, 판단 없음)

1. **appbar 타이틀 텍스트가 렌더에서 보이지 않는다.** 화면1·3·4·5·6·7·8·9의 `appbar_sub` 인스턴스는 내부 텍스트로 `"회원가입"`을 갖고 있지만(코드상 `text-white`), 배경도 `bg-white`라 흰 바탕에 흰 글자가 되어 **스크린샷에서 전혀 보이지 않는다.** 화면2는 배경 대신 아예 기본값 `"제목"`(오버라이드 안 된 placeholder로 추정)을 갖고 있는데 이것도 렌더에서 안 보인다. 실사용 영향은 없어 보이지만(뒤로가기 화살표만 보임) 데이터-렌더 불일치라 기록한다.
2. **이메일 도메인 "직접입력"(공백 없음, 콤보박스 안쪽) vs "직접 입력"(공백 있음, 바텀시트 리스트 안쪽)** — 같은 옵션인데 표기가 다르다(`I2449:31428;105:10739;160:4330` vs `2449:31476`).
3. **약관 상세(화면2) 본문에 조항이 "제1조(목적)"·"제2조(약관효력 및 변경)" 단 2개만 존재한다.** 프레임 구조상 이 2개가 전부이며, 3조 이후가 스크롤로 더 있는지는 이 파일 구조로는 확인 불가(스크롤 영역이 잘려 있지 않고 프레임 자체에 2개 그룹만 있음).
4. **상단 주소창·하단 브라우저 바가 라이브 컴포넌트가 아니라 정적 사진(비트맵 이미지, 레이어명 `KakaoTalk_Photo_2022-10-18-15-05-49 2`)이다.** `m.s1.co.kr` 텍스트만 별도 텍스트 레이어로 그 위에 얹혀 있고, 나머지 브라우저 크롬(상태바 아이콘·주소창 테두리·하단 뒤로/앞으로/홈/즐겨찾기/탭개수/메뉴 아이콘)은 전부 이미지 픽셀이다.
5. **가입완료 화면의 "홍길동님, 환영합니다!"는 샘플 데이터다.** 실제 서비스에서는 가입자 이름으로 치환될 자리표시자로 보인다(원본에 변수 처리 흔적 없음 — 하드코딩된 고정 텍스트).

## ❓ 미확인 항목

1. **appbar 타이틀 텍스트의 실제 의도** — 데이터상 `"회원가입"`(8개 화면) 또는 `"제목"`(화면2)이 들어있지만 전부 렌더에서 안 보인다(흰/흰 또는 미오버라이드). 의도적 디자인인지 원본 실수인지는 판단하지 않음(2단계/사용자 확인 필요할 수 있음).
2. **약관 상세(화면2)에 제3조 이후가 있는지** — 이 파일 구조상 제1조·제2조 2개 그룹만 존재. 스크롤로 더 있는 원본이 별도로 있는지는 이 섹션만으로 확인 불가.
3. **`직접입력`(공백없음, 화면7 콤보박스) vs `직접 입력`(공백있음, 화면8 리스트)** — 오타인지 의도적 구분인지 미확인.
4. **`get_screenshot`(Figma desktop 앱 경로)이 이 세션에서 계속 실패**(`No node could be found` — 여러 nodeId, 여러 화면에서 동일 에러). 대체 경로(`plugin_figma_figma__get_screenshot`, fileKey 명시)로 8개 화면 렌더를 확보해 실제로는 시각 검증을 완료했지만, 원래 지정된 도구 경로 자체는 이 세션에서 사용 불가 상태였다는 점은 사실로 남긴다.
