# Mobile Login 제작 이력 요약

이 문서는 다른 AI가 상세 실행 기록을 전부 읽지 않고도 중요한 변경의 순서를 파악하기 위한 요약이다. 세부 근거는 연결된 원문을 따른다.

## 2026-08-20 — 최초 리빌드와 패턴 승격

- 레거시 로그인 플로우를 로컬 정본 컴포넌트로 재구성했다.
- 원본 조사, 정본 매핑, 빌드, 독립 검증을 수행했다.
- 반복 가능한 모바일 로그인 구조로 판단해 `mobile-login` 패턴으로 승격했다.
- 상세: `1-inventory.md`~`5-registration.md`

## 2026-08-21 — 모바일 정본 보정

- PC형 모달을 모바일 Modal 정본으로 교체했다.
- 딤 영역의 좌우 패딩을 30px로 적용했다.
- 입력 A/B의 빈 키보드와 별도 앱 내비를 `NavBar / Platform=App + Keyboard`로 교체했다.
- 입력 상태, 긴 문구, 잘림, 컴포넌트 출처를 다시 검증했다.
- 상세: `3-build.md`, `4-verification.md`

## 2026-08-21 — 패턴 사양 정리

- 아이디 미입력·비밀번호 미입력 오류 화면 2종을 삭제해 현재 패턴을 11개 상태로 정리했다.
- 아이디 또는 비밀번호가 비어 있으면 로그인 버튼을 비활성화하도록 확정했다.
- 로그인 실패는 서버 판정 후 아이디·비밀번호 불일치 한 종류로 통합했다.
- 불일치 상태에서는 원인을 특정하지 않고 두 입력창 모두 오류로 표시한다.
- 에스원 CI 크기를 비율을 유지한 78.75×30으로 정정했다.
- 모달의 강제 최소 높이를 제거하고 콘텐츠 높이에 맞춰 HUG하도록 정리했다.
- 상세: `spec-change-2026-08-21.md`

## 2026-08-24 — 팝업 타이틀·본문·버튼 라벨 정정

- 자동 로그인 2개와 새로운 기기 3개 팝업의 현재 문구를 Figma에서 다시 읽어 기존 기록과 비교했다.
- 5개 팝업 모두 타이틀이 변경됐고, 자동 로그인 질문을 제외한 4개 팝업의 본문이 변경 또는 추가됐다.
- 자동 로그인 질문과 기기 등록 질문의 Dual 버튼은 `취소 / 확인`에서 `아니오 / 네`로 변경됐다.
- 나머지 Single 팝업 3개의 `확인` 버튼은 유지됐다.
- 현재 문구: `registry/patterns/mobile-login/copy.md`
- 변경 전·후 상세: `spec-change-2026-08-24-popup-copy.md`

## 2026-08-24 — 보조 링크 구분선 추가

- 회원가입·아이디 찾기·비밀번호 찾기 사이의 구분선이 11개 화면 전부에서 누락된 것을 확인했다.
- 레거시 규격(1×12)이 아니라 정본 Footer 규격(`sep` 1×10 · 좌우 8px · `color/line/gray/subtle`)으로 통일했다.
- 실측에서 `HelperLinks` 가 절대배치가 아니라 오토레이아웃(간격 16)임이 확인되어, 간격을 정본 값 8로 바꾸고 구분선을 흐름에 삽입했다.
- 줄이 가운데 정렬이라 폭이 2px 늘어난 만큼 좌우 링크가 각각 1px 대칭 재중심화됐다.
- 상세: `spec-change-2026-08-24-helper-separator.md`
