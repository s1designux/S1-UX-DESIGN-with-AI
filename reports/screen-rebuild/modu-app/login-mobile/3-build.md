## 실행 기록과 교정

- 빌더 전용 Figma 연결에서 첫 읽기 호출이 장시간 멈춰 중단됐다. 이후 🪞 screen-rebuilder가 빌드 JavaScript·판단을 담당하고, 루트 오케스트레이터가 같은 코드를 Figma에서 실행하는 operator 방식으로 우회했다. 역할 분리와 정본·검사 규칙은 그대로 유지되어 결과 기준에는 영향이 없다.
- 첫 화면 묶음은 Input/Button에 TEXT component property가 있을 것으로 가정한 사전검사에서 중단됐다. 캔버스 변경 전 실패라 Figma 변경은 0건이었고, 실제 하위 TEXT 이름(`입력`, `텍스트`, `안내 메세지`, `버튼`)을 읽어 descendant override 방식으로 수정했다.
- 모달 묶음은 버튼 TEXT가 Modal 직계가 아니라 내부 `primary`·`secondary` 인스턴스에 있다는 사전검사에서 중단됐다. 역시 변경 0건이었고, Single/Dual 내부 버튼 순서를 확인한 뒤 수정했다.
- 키보드 플레이스홀더가 처음에 `level-0`으로 연결된 2건을 `color/bg/level-1`로 교정했다: `1564:141`, `1564:214`.
- Footer 기본 문구와 원본이 달랐던 11개 화면을 `이용약관 / 개인정보처리방침 / 영상정보처리방침`으로 교정했다.
- 원문은 맞지만 레이어명이 달랐던 보조 로그인 버튼 3건의 이름을 `Button / 휴대전화번호로 로그인`으로 통일했다.

### 독립 검증 FAIL 후 교정

첫 독립 Phase 4 검증은 두 가지 수정 사항을 찾았고, Phase 3로 돌아와 모두 교정했다.

- **P1 · 로그인 본문 간격:** 13개 화면의 단일 간격을 구간별 spacer로 바꿨다. 모든 화면의 ID 입력은 y=188로 복원했고, 일반·키보드 화면의 로그인 버튼은 y=330, 오류 화면은 y=368로 맞췄다. 키보드 2개는 기존 y=439를 유지했다.
- **오류 화면 보정:** 아이디 오류 화면 `1562:6`은 70px 오류 Input을 반영해 비밀번호 y=286, 로그인 y=368로 맞췄다. 비밀번호 오류 화면 `1562:7`은 70px 오류 Input 뒤 간격을 별도로 조정해 로그인 y=368로 맞췄다. 잘못된 아이디·비밀번호 화면 `1562:8`의 86px 오류 Input도 로그인 y=368을 유지한다.
- **긴 모달 문구:** 신규기기 A·C의 본문을 부모 폭에 채우는 방식으로 바꾸고 폭을 310px로 고정했다. 높이는 문구 길이에 맞춰 늘어나며, 잘림과 화면 밖 넘침은 0건이다.
- **P2 · 노드 추적:** `skipInvisibleInstanceChildren=false`로 두 번 나눠 전수 재조회했다. 현재 인스턴스는 145개이며 루트 105개, 로컬 112개, 허용 V2.2 원격 아이콘 33개다. 금지 출처는 0건이다.
- `node-map.json`에는 13개 화면의 authored 노드, 루트 인스턴스, 내부의 보이지 않는 아이콘을 포함한 모든 인스턴스, 현재 보이는 텍스트, 새 spacer와 최종 위치를 실제 ID로 기록했다. 레이어명 교정 ID `1564:61`, `1564:284`, `1564:363`도 명시했다.
- **추가 재검증 · Input 내부 폭:** 화면에 놓인 Input 바깥 폭은 320px였지만 정본 인스턴스 내부 `field`가 기본 200px로 남아 있던 26건을 발견했다. 바깥 폭과 높이는 유지하고 내부 `field` 26개를 모두 320px + 가로 채움(`FILL`)으로 교정했다.
- **추가 재검증 · 키보드 화면 보조 링크:** 입력 A/B 화면에 빠졌던 `회원가입 / 아이디 찾기 / 비밀번호 찾기`를 복원했다. 보조 링크는 y=398, 로그인은 y=330, 키보드는 y=439를 유지하며 휴대전화 로그인 버튼은 추가하지 않았다. 새 노드는 입력 A `1586:4034`~`1586:4038`, 입력 B `1586:4046`~`1586:4050`이다.
- 교정 후 compact live 검사와 두 분할 trace를 다시 실행했다. Input 26/26, 키보드 보조 링크 2/2, 위치·필수 문구·raw 색·화면 밖 넘침·출처 검사가 모두 통과했으며 출처 집계는 145/112/33으로 유지됐다.
