## 2. 왜 이 일을 시작했나 (river 의 원래 요구)

river 는 **비개발자 UX 디자이너**이고, 컴포넌트를 계속 채워나가는 중이다(현재 42개, 영상 도메인 위젯 5세트가 Figma 완료·코드 미착수로 대기). 요구는 셋:

1. 토큰 파이프라인을 더 정확·효율적으로 관리
2. 옛 프로토타입/땜질/구멍은 **고치기보다 새로 만드는 게 나으면** 그렇게
3. **데이터가 많아져도 코드·Figma 라이브러리·검수기·설치기가 오류 없이** 함께 돌 것

추가로 river 가 설명한 **실제 작업 방식**(이 계획의 설계 기준):
> 앞으로의 컴포넌트 추가는 "무엇을 만들어줘"가 아니라 **레거시 → 정본 변환**이다.
> 레거시 Figma 컴포넌트 세트나 완료된 프로젝트 GUI 화면을 주면 → 시멘틱 기준으로 매칭 →
> 없으면 시멘틱부터 생성 → 최신 정본으로 변환 → 최신 디자인 기준으로 수정 → **다크모드도 함께**.
> 이후 **이동체·모두앱 등 도메인이 계속 추가**될 예정이다.

## 3. 진단 결론 (이 계획 전체를 관통하는 한 문장)

**기계(게이트)가 지키는 층은 건강했고, 사람이 지키는 층만 병들어 있었다.**

## 5. 이 프로젝트에서 지켜온 작업 원칙 (새 세션도 따를 것)

1. **격리 작업트리에서 작업 → 게이트 통과 확인 → main 병합.** 원본에서 직접 작업하지 않는다.
2. **`build-components.ts` 구조 변경은 ⭐ 단독 자가검증 금지** — `component-verifier` 를 실제 spawn 해 검증하고 Gate 13 에 기록. (이번 작업에서 7회 spawn 했고 **매번 결함이 나왔다**. 예: 면제 목록 거짓 선언으로 게이트 침묵 · 실패 정리의 오삭제 · UI 거짓 단언 · 열화 과소보고 · 반대 방향 거짓 경보. 전부 backlog 로 미루지 않고 그 자리에서 고쳤다.)
3. **UI/HTML/CSS 를 건드렸으면 크기 불문 렌더 1회 확인**(헤드리스 크롬 스크린샷).
4. **정본에 없는 값을 지어내지 않는다.** Phase 4d 에서 CSS 를 신설할 때도 정본(build-components.ts)의 수치·토큰을 그대로 옮겼고, 새 디자인은 0건이었다.
5. **부채는 baseline 동결, 신규만 차단**(래칫). 게이트를 갑자기 조이면 `--no-verify` 우회를 부르고 그러면 게이트 생태계 전체가 죽는다.
6. **`--no-verify` 금지.** 이번 작업에서 0회 사용했다.

## 7. river 에게 물어야 할 열린 질문 3개 (앞 세션에서 못 받은 답)

> 전부 **값·디자인 문제가 아니라 이름 규칙/범위 결정**이다. 쉬운 말로 물을 것.

**Q1. 표 셀 크기 이름이 정본 안에서 다르다.**
표는 `md/sm`, 표 **셀**은 `SMALL/MEDIUM`. 높이는 3곳(설치기 Table·Table Cell·웹) 모두 **44/38 로 완전히 같은 것을 확인**했다. 이름만 다르다.
- (A) 설치기 이름을 md/sm 으로 통일 — 정본이 한 어휘가 되지만 **Figma 라이브러리의 '표 셀' 변형 이름이 바뀌고**, 그걸 쓰는 기존 디자인 파일에 영향이 갈 수 있다
- (B) 이름은 두고 "둘은 같은 것"이라고 기계에 알려주는 별칭 처리 — Figma 영향 0, 대신 어휘 두 가지가 남는다
- 안 정하면: 지금처럼 목록에 남고 아무 일도 안 일어난다

**Q2. GNB 유틸 아이콘 속성 이름에 띄어쓰기가 있다(`full menu`).**
아이콘 조합 5종 **표출은 이미 끝냈다.** 다만 웹 속성명에는 공백을 못 써서 검사 연결만 못 하고 있다.
- (A) 검사기가 공백을 알아서 처리하게 — Figma 영향 0, 앞으로 같은 이름이 또 생겨도 자동 처리
- (B) 설치기 속성명을 `fullmenu` 로 개명 — 이름은 깔끔해지지만 Figma 변형 이름이 바뀐다
- 안 정하면: 표출은 되지만 그 축만 검사에서 빠진 채 남는다

**Q3. 모바일 시간 선택 바텀시트(숫자 휠 굴리는 화면)가 웹 가이드에 아예 없다.**
정본 수치와 토큰은 다 있어서 그대로 옮길 수 있다. 다만 **위아래가 흐려지는 효과**를 웹에서 구현하는 방식(그라데이션 마스크)은 Figma 와 1:1 대응이 아니라 한 번 정하면 된다.
- (A) 지금 만든다 (구현 방식은 명시해서 기록)
- (B) 나중에 — 목록에 남겨두고 Phase 5 로 넘어간다
