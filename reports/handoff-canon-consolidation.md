### 왜 나뉘어 있나 (확인된 이유)

- **vars-data ↔ textstyles-data 분리는 Figma 구조 때문**이다. Variables 와 Text Styles 는 Figma 에서 다른 기능이고 설치 API 도 다르다(`install-textstyles.ts` 전담). **기술적 강제라 합치기 어렵다.**
- 나머지 분리(registry·governance)는 **역사적 이유**로 보인다 — 검증 필요.

### 이번 세션에서 드러난 "나뉘어서 생긴" 실제 피해

1. **텍스트 스타일 정본은 게이트가 0개였다** — 게이트 대부분이 `vars-data` 만 보도록 만들어져 있었음
2. **우산 명령(`tokens:reconcile`)이 9단계 전부 vars-data 기준**이라, 텍스트 스타일을 추가해도 파생이 안 따라왔음 → `typo:gen` 을 1단계로 편입(9→10)
3. `registry/components/tab.json` 이 정본과 어긋난 값을 3건 갖고 있었음(indicator 4px·존재하지 않는 토큰 참조·높이 필드 혼선)
4. `CLAUDE.md` 안의 반복요청 승격 표가 JSON 정본과 드리프트 → **표를 삭제**하고 JSON 단일 정본화

### 논의할 질문 (새 세션에서)

- 합칠 수 있는 것과 **기술적으로 못 합치는 것**을 먼저 가른다(Figma 구조 강제 vs 역사적 분리)
- 못 합치는 것은 **"한 명령·한 게이트로 묶어" 사용자가 한 곳처럼 다루게** 할 수 있나 (우산 명령·Gate 34 가 이미 두 파일을 함께 본다 — 이 방향의 확장)
