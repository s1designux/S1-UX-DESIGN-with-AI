# 화면 조립 규칙 채록 — 장비 상태 요약 패널 (2026-09-16)

> 정본 `registry/governance/composition-rules/`(낱장 — 규칙 1개 = 파일 1개) 의 근거 문서. 규칙 자체는 그 낱장들이 정본이고, 여기는 **어떻게 나왔는지**를 남긴다.
> 상태: **candidate · 게이트 미배선.** 승인된 판정 기준이 아니다.

## 왜 이 문서가 생겼나

토큰·컴포넌트 정본은 "이미 고른 부품을 **어떻게 그리는가**"만 담는다.
배포본 컴포넌트 CSS 27종(3,517줄)을 전수로 읽고 정본 `build-components.ts`(7,443줄)의 수치 분포와 대조해도
"**어느 부품을 고르고 어디에 놓는가**"는 나오지 않았다. 부품 하나하나는 자기가 어디에 놓일지 모르기 때문이다.

2026-09-16 실험에서 이 빈칸이 드러났다. 같은 기능·같은 내용의 두 안이 배포본 검사기
(`ui-library/dist/tools/s1-ui-lint.mjs`)를 **둘 다 오류 0·경고 0** 으로 통과했는데 서로 다른 계열로 보였다.
그 차이의 대부분이 이 층에 있었고, river 가 말로 7개를 꺼내 주었다.

## 실험 조건

- 대상: **장비 상태 요약 패널** — 배포본에 없는 유형. `registry/governance/intentional-unused-tokens.json` 이
  `color/status-card/text/*` 8종을 "status-card 컴포넌트 미구현 — 빌드 시 연결"로 등록해 둔 자리다.
- 내용 고정: 단말 4대(정상 2 · 응답 없음 1 · 점검 중 1) · 새로고침 · 전체 보기. 모든 단계에서 동일.
- 코어 부품은 배포본 그대로 쓰고 **코어 스타일을 덮어쓰지 않았다.** 조정한 것은 조합의 배치·여백·부품 선택뿐.
- 렌더: 헤드리스 크롬(`scripts/render-shot.js`), 라이트·다크 각 1벌.

## 이 실험에서 바로잡은 것

- **자간은 굵기가 결정하지 않는다.** 정본은 이름 붙은 텍스트 스타일 19종이고 자간은 각 스타일에 열거된 속성이다
  (`textstyles-data.ts` 머리 주석). 굵기와 상관돼 보인 이유는 `build-components.ts:123-133` 의
  `textStyleKey(size, weight)` 가 **Bold 면 title/, 아니면 body/** 로 보내기 때문이다. 굵기는 계열을 고르는 라우팅일 뿐이다.
  반례: `title/14M`(Medium·자간 0) · `title/20R`(Regular·자간 0).
- **"꼬리 아이콘이 있으면 오른쪽을 한 칸 줄인다"는 틀린 서술이었다.** 줄이는 양이 4·6·8 로 제각각이라 규칙에서 내렸는데,
  R-6 이 이유를 설명한다 — 맞추는 것은 값이 아니라 **보이는 여백**이고, 빼는 양은 아이콘마다 다르다.
- **비교의 잣대를 손으로 만들면 잣대가 틀린다.** 기준으로 쓰던 "기존 승인 UI" 표를 손으로 조립하면서
  페이지네이션의 화살표 네 개(처음·이전·다음·마지막)를 빠뜨렸다. river 가 발견했고 배포본 예제 마크업으로 교체했다.
  이후 비교 화면은 `ui-library/dist/examples/*.html` 을 그대로 쓴다.

## 막힌 것 (needs-decision)

1. **새로고침 아이콘이 웹 배포본에 없다.** 승인 목록(`registry/figma/allowed-remote-keys.json`)에는 `refresh` 가 있고
   Video/Widget Header 가 쓴다. 웹 자산으로 내려오지 않았다. R-1 을 실제 화면에 쓰려면 이게 먼저다.
   실험 렌더는 아이콘 라이브러리 원본 PNG(`assets/icons/ic_새로고침_line.png`)를 임시로 얹었다.
2. **테두리 없는 아이콘 버튼이 독립 부품으로 없다.** 정본 `build-components.ts` 에 해당 빌더가 없고,
   웹에서는 modal·modal-content·mobile-header·input·bottom-sheet·date-picker 안쪽 part 로만 존재한다.
   `ui-library-code-contract.json:208` 이 "다른 코어 컴포넌트의 내부 part 를 선택하거나 시각 스타일을 override 하지 않는다"고
   못박고 있어, 지금 상태로는 화면에서 가져다 쓸 수 없다.

## 함께 발견한 것 (고치지 않음)

- `status-card` 역할 토큰 사이에 같은 색값이 있다 — 다크에서 `tertiary--sub` = `disabled`(gray-dark/400),
  라이트에서도 같다(gray/300). 같은 자리에 나란히 쓰이는지는 컴포넌트가 없어 판단 보류.
- `title/14M` 은 승인된 정본 항목인데 사용처 0곳. 표 헤더는 여전히 `body/14M` 으로 간다.
- `pages/layer-policy.html` 이 설명하는 표면 위계 토큰 이름 5개 중 3개가 실재하지 않는다
  (`--color-bg-default`·`bg-subtle`·`surface-default`). 실제 배선은 `--color-bg-level-0~3`.
