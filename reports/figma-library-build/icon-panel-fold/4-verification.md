## 4. 형태 원본 대조 (vectorPaths 원자료, 반올림 없음)

좌표는 variant 기준(벡터 위치 + 경로 좌표). Figma 내부 수치는 1/1024 단위로 저장되므로 1.08 → 1.080078 차이는 저장 형식이다.

|---|---|---|---|
| 외곽 테두리 (Solid·Line) | rect 3.54 stroke 1.08 → 바깥 3~21, 안쪽 4.08~19.92 | 바깥 사각 3~21 + 안쪽 사각 4.08~19.92 을 **반대 방향**으로 감은 한 경로, windingRule NONZERO | ✅ |

| 세로선 (Line) | M9 3V21 stroke 1.08, 끝 butt | x 8.46~9.54 × y 3~21 | ✅ |

| 왼쪽 판 (Color) | rect 3,3,6×18 | 3~9 × 3~21 | ✅ |

**Solid 의 흰 구멍 판정: 정상.** 원본 solid SVG 는 왼쪽 판만 채우고 외곽은 선(`fill` 없음)이다. Figma 외곽 벡터는 바깥 사각과 안쪽 사각이 서로 반대로 감겨 있어 NONZERO 규칙에서 안쪽(4.08~19.92)이 비는 것이 맞다. 잘못 채워지거나 선이 사라진 곳 없음 — 렌더에서도 테두리 두께 1.08 이 네 변 모두 보이고, 오른쪽 판 안쪽은 비어 있다.

Color 의 몸통·왼쪽 판은 windingRule `NONE` 이다. 이웃 ic_메뉴 Color 벡터도 같은 값이며, 렌더에서 두 판 모두 채워져 그려짐을 확인했다.
