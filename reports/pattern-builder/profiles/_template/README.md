# 새 묶음 여는 법

1. 이 폴더를 통째로 복사해 `profiles/<매체>-<서비스>/` 로 만든다.
2. `profile.json` 을 채운다. 레거시 서비스면 `kind`=`legacy`, `canonPolicy`=`separate`.
3. 판독할 화면이 있으면 먼저 모은다 → `reports/pattern-builder/inventory/<service>/`
4. 다섯 갈래를 **근거가 생긴 것만** 채운다. 근거 없는 항목은 `미작성`으로 둔다.
5. `profiles/README.md` 맨 아래 표에 한 줄 추가한다.
