# 화면 갈래

> 이 묶음(매체 + 서비스) 안에서만 쓴다. 다른 묶음에 옮겨 쓰지 않는다.
> 판독한 화면이 어떤 갈래로 갈리는지, 갈래마다 무엇으로 알아보는지 적는다.
> **잘게 쪼개지 않는다.** 갈래는 나중에 "이것도 챙겼나" 짚어보려고 나누는 것이라,
> 지시가 같아지는 것끼리는 한 갈래로 둔다(예: 화면이 빈 것과 팝업 안이 빈 것 = 「내용이 없을 때」).
> 숫자도 정확할 필요 없다. 챙겼는지 안 챙겼는지가 보이면 된다.
