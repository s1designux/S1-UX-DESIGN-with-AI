# 화면 상태 규칙

> 묶음 `pcweb-bus` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성
> 근거: 폭 1920 화면 800장 판독.

## 이 서비스가 실제로 그린 상태

| 상태 | 화면 | 메모 |
|---|---|---|
| 겹쳐 뜨는 창(팝업) | 208 | 웹은 화면을 넘기는 대신 겹쳐 띄워 처리한다 |
| 입력 중 | 123 | 이름에 「입력」 |
| 보는 사람이 다를 때 | 111 | `(일반 사용자 ver)` · `(관리자 ver)` 로 두 벌 그렸다 |
| 안내 | 104 | 확인을 받기 전에 알린다 |
| 고르는 중 | 96 | 이름에 「선택」 |
| 기본 | 69 | 이름에 「Default」 |
| 내용이 없을 때 | 23 | |
| 펼침·접음 | 11 | 메뉴와 목록을 접었다 폈다 |
| 오류 | 7 | 적게 그렸다 |

## 읽어낸 것

- **권한에 따라 화면을 두 벌 그린다**(111장). 같은 게시판을 일반 사용자용과 관리자용으로 나눠 그렸다.
  이 묶음으로 화면을 만들 때 "보는 사람이 누구인가"를 먼저 정해야 한다.
- **오류가 7장뿐**이다. 실패했을 때를 거의 안 그렸다.
