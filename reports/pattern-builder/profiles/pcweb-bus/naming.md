# 이름 짓기 규칙

> 묶음 `pcweb-bus` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성

## 화면 이름

- 관찰 · **`영역_기능_상태`** 를 밑줄로 잇는다. 800장 중 776장이 밑줄을 쓰고, 평균 3.3 조각으로 앱보다 길다.
- 관찰 · 웹 화면은 앞에 **`웹_`** 을 붙이는 경우가 많다(193장).
- 관찰 · 앞머리 영역은 노선 검색(126) · 출퇴근 버스 신청(86) · 전체(54) · 게시판(48) 순이다.

## 상태를 이름에 붙이는 방법

- 관찰 · 굳어진 낱말 — 팝업(201) · 입력(123) · case(119) · 안내(104) · 선택(96) · 상태(73) · Default(69).
- 관찰 · **보는 사람이 다르면 이름 끝에 `(일반 사용자 ver)` · `(관리자 ver)` 를 붙인다**(111장).
  같은 화면을 권한별로 두 벌 그려 두었다는 뜻이다.
