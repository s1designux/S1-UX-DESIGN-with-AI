# pcweb-bus — PC 웹 · 삼성통근버스 (탑승자)

> 이 묶음 안에서만 쓴다. **정본에 합치지 않는다.** 묶음 구조는 [../README.md](../README.md)

관계사 통근버스를 타는 사람이 쓰는 웹 화면이다. 같은 서비스의 앱은 [`app-bus`](../app-bus/README.md),
관리자 화면은 [`pcweb-busadmin`](../pcweb-busadmin/README.md) 에 따로 있다.

판독: Figma `[최종] 삼성통근버스` GUI 페이지 13장 · 폭 1920 화면 **800장** (2026-09-18, Admin 페이지 제외)

## 이 서비스의 특이점

- **부품 이름이 매체로 갈려 있다** — `C/`(공용) · `W/`(웹) · `M/`(모바일). 웹 화면은 `C/` 와 `W/` 를 쓴다.
- 화면 기준은 **1920 × 1080**(402장).
- 맨 위 가로 메뉴줄(GNB)이 거의 모든 화면에 있다(616/800).
