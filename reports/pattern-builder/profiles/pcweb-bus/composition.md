# 부품 조합 규칙

> 묶음 `pcweb-bus` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성

## 이 서비스의 부품 이름 규칙

- 관찰 · 부품 이름이 매체로 갈려 있다 — `C/`(공용) · `W/`(웹) · `M/`(모바일). 웹 화면은 `C/` 와 `W/` 를 쓴다.
- 관찰 · 이름은 `갈래/역할/크기` 꼴로 이어 붙인다. 예) `C/BTN/basic_L` · `W/GNB/topbar/tab`

## 많이 쓰인 부품

- 관찰 · 메뉴줄 탭(2526) · 목록 구분선(2354) · 필터 화살표(1527) · 드롭다운 목록(1505) · 기본 버튼(1497)
