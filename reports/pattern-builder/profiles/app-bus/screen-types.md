# 화면 갈래

> 묶음 `app-bus`(휴대폰 앱 · 삼성통근버스 탑승자) 전용 — 정본에 합치지 않는다.
> 근거: 폭 360 화면 633장 판독.

| 갈래 | 화면 | 무엇으로 알아보나 |
|---|---|---|
| **도메인 고유** | 172 | 버스 위치·노선 안내·탑승 확인처럼 이 서비스에만 있는 화면 |

## 이 갈래에서 읽어낸 것

- **바텀시트를 많이 쓴다**(43). 모두앱은 6장뿐이었다. 앱에서 고르는 일을 바텀시트로 처리하는 서비스다.
- **검색이 41장**으로 큰 갈래다. 노선·정류장을 찾는 것이 이 서비스의 중심 행동이다.
- **내용이 없을 때를 적게 그렸다.** 모두앱이 화면마다 빈 경우를 따로 그린 것과 다르다. 이 서비스 화면을 만들 때는 빈 경우가 빠지지 않았는지 한 번 더 짚어야 한다.

## 기계가 미리 묶어둔 것

로컬 모델이 화면 이름과 부품만 보고 닮은 것끼리 **172묶음**으로 갈라둔 것이 있다
(`../../inventory/commuter-bus/similar-clusters.md`). 기능 흐름 단위로 묶이는 편이다 —
게시판 답글 85 · 홈 팝업 83 · 귀성버스 신청 83 · 회원가입 59 · 게시판 상세 57.
위 갈래표와 다른 각도로 보인다. 둘 다 참고용이고, 판정은 사람이 한다.
