# app-bus — 휴대폰 앱 · 삼성통근버스 (탑승자)

> 이 묶음 안에서만 쓴다. **정본에 합치지 않는다.** 묶음 구조는 [../README.md](../README.md)

관계사 통근버스를 타는 사람이 쓰는 앱 화면이다. 같은 서비스의 웹은 [`pcweb-bus`](../pcweb-bus/README.md),
관리자 화면은 [`pcweb-busadmin`](../pcweb-busadmin/README.md) 에 따로 있다.

판독: Figma `[최종] 삼성통근버스` GUI 페이지 13장 · 폭 360 화면 **633장** (2026-09-18)

## 이 서비스의 특이점

- **부품 이름이 매체로 갈려 있다** — `C/`(공용) · `M/`(모바일) · `W/`(웹). 앱 화면은 `C/` 와 `M/` 를 쓴다.
- 화면 높이 기준이 **812**(540장)다. 모두앱의 780과 다르다.
- 같은 기능을 웹과 앱 두 벌로 그려 뒀다. 한 페이지 안에 웹 화면과 앱 화면이 나란히 있다.
