# 화면 상태 규칙

> 묶음 `app-bus` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성
> 근거: 폭 360 화면 633장 판독.

## 이 서비스가 실제로 그린 상태

| 상태 | 화면 | 메모 |
|---|---|---|
| 겹쳐 뜨는 창(팝업·바텀시트) | 150 | 앱에서 고르고 알리는 일을 여기서 처리한다 |
| 고르는 중 | 116 | 이름에 「선택」 |
| 안내 | 67 | 이름에 「안내」 — 확인을 받기 전에 알린다 |
| 입력 중 | 50 | 이름에 「입력」 |
| 기본 | 33 | 이름에 「Default」 |
| 단계 진행 | 28 | `STEP1`·`STEP2` 로 적는다 |
| 스크롤 위치 | 18 | 최상단·최하단을 따로 그렸다 |
| 내용이 없을 때 | 8 | 적게 그렸다 — 만들 때 빠지지 않았는지 짚을 것 |
| 오류 | 7 | 적게 그렸다 |

## 읽어낸 것

- **바텀시트가 상태의 한 축이다.** 모두앱은 화면을 넘겨 처리한 일을 이 서비스는 아래에서 올려 처리한다.
- **내용이 없을 때와 오류를 적게 그렸다.** 이 묶음으로 화면을 만들 때 먼저 짚어야 할 두 가지다.
- 눌림·초점 같은 낱낱의 상태는 화면 이름에 없다. 부품 쪽에서 다룬 것으로 보인다 — 미확인.
