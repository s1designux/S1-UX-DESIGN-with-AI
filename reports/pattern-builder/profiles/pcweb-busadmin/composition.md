# 부품 조합 규칙

> 묶음 `pcweb-busadmin` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성
> 근거: Admin 페이지 화면 112장 판독 + 24장 실측.

## 부품 이름 규칙

- 관찰 · 탑승자 웹과 같은 부품을 쓴다 — `C/`(공용) · `W/`(웹). 새로 만든 관리자 전용 부품은 보이지 않는다.

## 글자 — 탑승자 웹보다 한 단계 크다

- 관찰 · **16 중간이 압도적**(638)이고 그다음이 14 중간(263) · 20 굵게(179) 다.
  탑승자 웹은 14 중심인데 관리자는 16 중심이다.
- 관찰 · 줄 간격은 글자 크기와 같다(16→16 · 14→14 · 20→20).
- 관찰 · **빨강 `#FF4555` 가 230회로 유난히 많다.** 필수 표시와 경고가 화면마다 있다는 뜻이다.

## 많이 쓰인 덩어리

- 관찰 · 왼쪽 메뉴 줄 320×56(115) · 아이콘 자리 40×40(48) · 버튼 156×50 · 164×50.

## 화면에 직접 놓지 않는 것

- 관찰 · 팝업이 화면의 대부분이다(72/112). 겹쳐 뜨는 것이라 뼈대의 칸으로 잡지 않는다.
