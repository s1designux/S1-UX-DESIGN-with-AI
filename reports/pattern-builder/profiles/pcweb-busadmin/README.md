# pcweb-busadmin — PC 웹 · 삼성통근버스 (관리자)

> 이 묶음 안에서만 쓴다. **정본에 합치지 않는다.** 묶음 구조는 [../README.md](../README.md)

통근버스 사이트를 관리하는 사람이 쓰는 화면이다. 탑승자 화면과 쓰는 사람도 화면 구성도 달라 따로 둔다.

판독: Figma `[최종] 삼성통근버스` · `GUI_Admin` 페이지 · 폭 1920 화면 **112장** (2026-09-18)

## 이 서비스의 특이점

- **화면의 대부분이 겹쳐 뜨는 창이다** — 112장 중 72장이 팝업. 목록 화면 위에서 팝업으로 고치고 저장하는 방식.
- 입력 폼이 33장으로 그 다음이다. 관리자 화면은 **보기보다 고치기** 중심이다.
- 빈 상태·오류 화면은 거의 없다(각 1~2장). 탑승자 화면과 크게 다른 점이다.
