# 화면 갈래

> 묶음 `pcweb-busadmin`(PC 웹 · 삼성통근버스 관리자) 전용 — 정본에 합치지 않는다.
> 근거: `GUI_Admin` 페이지의 폭 1920 화면 112장 판독.

| 갈래 | 화면 | 무엇으로 알아보나 |
|---|---|---|
| **팝업** | 72 | 이름에 「팝업·모달」 — 겹쳐 뜸 |
| **입력 폼** | 33 | 입력 부품 3개 이상 |
| **도메인 고유** | 2 | 이 서비스에만 있는 화면 |
| **오류** | 2 | 이름에 「오류·에러」 |
| **선택 목록** | 1 | 체크·라디오 3개 이상 |
| **알림·대기** | 1 | 로딩·토스트 |
| **내용이 없을 때** | 1 | 이름에 「없음」 — 다만 이 한 장은 실제로는 버튼을 뺀 변형이라 빈 상태가 아니다 |

## 이 갈래에서 읽어낸 것

- **거의 전부가 팝업과 입력 폼**(105/112)이다. 관리자 화면은 목록을 띄워 놓고 그 위에서 고쳐 저장하는 방식이다.
- **내용이 없을 때와 오류를 거의 그리지 않았다.** 탑승자 화면과 가장 다른 점이다. 관리자 화면을 손볼 때 빈 경우와 실패를 먼저 짚어야 한다.
- 탑승자 웹과 부품은 같은 것을 쓰지만 **화면이 하는 일이 다르다** — 그래서 묶음을 나눴다.

## 기계가 미리 묶어둔 것

로컬 모델이 화면 이름과 부품만 보고 닮은 것끼리 **172묶음**으로 갈라둔 것이 있다
(`../../inventory/commuter-bus/similar-clusters.md`). 기능 흐름 단위로 묶이는 편이다 —
게시판 답글 85 · 홈 팝업 83 · 귀성버스 신청 83 · 회원가입 59 · 게시판 상세 57.
위 갈래표와 다른 각도로 보인다. 둘 다 참고용이고, 판정은 사람이 한다.
