# 화면 상태 규칙

> 묶음 `pcweb-busadmin` 전용 — 정본에 합치지 않는다. 상태 표기: 확정 / 관찰 / 미작성
> 근거: Admin 페이지 화면 112장 판독.

## 이 서비스가 실제로 그린 상태

| 상태 | 화면 | 메모 |
|---|---|---|
| 겹쳐 뜨는 창(팝업) | 73 | 화면의 대부분. 목록 위에 띄워 고치고 저장한다 |
| 안내 | 35 | 저장·삭제 전에 알린다 |
| 입력 중 | 29 | |
| 고르는 중 | 18 | |
| 오류 | 11 | **탑승자 화면보다 비중이 높다** — 잘못 넣었을 때를 챙겼다 |
| 기본 | 9 | |
| 내용이 없을 때 | 1 | 거의 안 그렸다 |

## 읽어낸 것

- **고치는 화면이라 오류를 챙겼고, 비어 있을 때는 안 챙겼다.** 관리자는 데이터가 있는 상태를 전제로 그렸다.
- 팝업 안에서 일이 끝난다. 화면을 넘기는 흐름이 거의 없다.
