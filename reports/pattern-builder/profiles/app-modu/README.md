# app-modu — 휴대폰 앱 · 모두앱 (레거시 묶음)

> **이 폴더의 내용은 정본에 합치지 않는다.** (river 결정 2026-09-18)
>
> 모두앱은 이미 운영 중인 서비스이고 레거시 가이드라인이 적용된 상태다.
> 여기에 최신 컴포넌트를 억지로 끼워 넣거나, 모두앱에서 뽑은 패턴을 최신 가이드에 병합하면 안 된다.
> 이 폴더는 **모두앱을 손볼 때 쓰는 별도 기준**이고, 정본(토큰·컴포넌트·패턴)에는 어떤 영향도 주지 않는다.
> 묶음 구조 전체는 [../README.md](../README.md) 참조.

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `screen-types.md` | 화면이 어떤 갈래로 갈리나 (16갈래) |
| `screen-skeleton.md` | 모두앱 화면의 세로 칸 나눔·폭·여백 |
| `composition.md` | 모두앱에서 쓰인 부품 조합 |
| `states.md` | 모두앱 화면 상태 |
| `content.md` | 모두앱 문구·오류·접근성 |
| `naming.md` | 모두앱 화면 이름 규칙 |
| `list-row/` | 이 묶음 전용 목록 줄 — 정본 부품으로 승격하지 않는다 |
| `list-screen.html` | 이 묶음의 목록 화면 시안 |
| `profile.json` | 매체·서비스·갈래 선언 |
| `../../inventory/modu-app/` | 판독 원자료와 판독표 |

## 지키는 선

- 여기 수치는 모두앱 레거시에서 읽은 것이다. 최신 가이드의 값과 달라도 그것이 정상이다.
- 최신 가이드를 고칠 근거로 이 폴더를 인용하지 않는다.
- 반대로, 최신 가이드가 바뀌어도 이 폴더를 따라 고치지 않는다.
- 새 서비스·새 화면은 최신 가이드로 만든다. 이 폴더는 모두앱을 건드릴 때만 본다.
