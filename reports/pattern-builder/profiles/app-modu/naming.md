# 이름 짓기 규칙

> 묶음 `app-modu`(휴대폰 앱 · 모두앱) 전용 — 정본에 합치지 않는다. 배경은 [README.md](README.md)
> 상태 표기: 확정 / 관찰 / 미작성

## 패턴 id

- 확정 · kebab-case 고유 id. (근거: 빌더 패턴 목록의 항목 서식)

## 패턴 이름(사람이 읽는 것)

- 미작성

## 화면 이름

- 관찰 · 레거시는 **`영역번호.기능번호 기능명_순번 상태`** 꼴을 쓴다. 예) `4.2 권한 신청_3 계약 검색 조건 선택`. 번호로 시작하는 이름 다수.
- 관찰 · 밑줄 앞이 기능, 밑줄 뒤가 그 기능 안의 단계·상태다(대부분).

## 상태를 이름에 붙이는 방법

- 관찰 · 상태 낱말이 굳어져 있다 — 메인 · 없음 · 선택 · 검색 · 상세 · 미권한 · 동의 · 팝업 · 완료.
- 미작성 · 이 낱말들을 정본 상태 이름으로 확정할지 여부
