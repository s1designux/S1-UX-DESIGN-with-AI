# S-1 GUI Builder — 피그마 화면 보내기

피그마에서 화면을 고르고 단추를 누르면, **그 화면의 그림과 숫자가 파일 한 장으로 내려받아집니다.**
열쇠(개인 토큰)도, 켜둬야 할 사이트도 필요 없습니다. 피그마를 볼 수 있으면 누구나 씁니다.

읽기만 합니다. 피그마 파일을 고치지 않고, 바깥으로 아무것도 보내지 않습니다.

---

## 처음 한 번 — 플러그인 넣기

1. 이 폴더(`plugins/s1-gui-builder`)를 통째로 자기 PC에 받아 둡니다.
2. 피그마 데스크톱 앱에서 **Plugins → Development → Import plugin from manifest…**
3. 이 폴더의 `manifest.json` 을 고릅니다.

목록에 **S-1 GUI Builder** 가 생기면 끝입니다.

## 쓰는 법

1. 피그마에서 보낼 **화면(프레임)을 드래그로 고릅니다.** 묶음 상자(섹션)를 고르면 그 안의 화면까지 알아서 펼칩니다.
   아무것도 고르지 않으면 **그 페이지의 화면 전부**를 담습니다.
2. 플러그인을 열고 **파일로 내려받기**.
3. 다운로드 폴더에 `s1-screens_파일이름_페이지_날짜.json` 이 생깁니다. 그 파일을 넘기면 됩니다.

창의 선택 두 개:

| 선택 | 언제 끄나 |
|---|---|
| 화면 그림(PNG)도 같이 담기 | 숫자만 필요할 때. 파일이 훨씬 가벼워집니다. |
| 속까지 깊게 훑기 | 기본은 8겹까지. 깊은 곳 값까지 봐야 할 때만 켭니다(느리고 커집니다). |

## 빌더에서 바로 열기 (가장 쉬운 길)

패턴 빌더를 열고 왼쪽 **가져온 화면** 칸 → **📂 기존화면 불러오기** → 내려받은 파일을 고릅니다.
화면이 칸(위에서 아래로 쌓인 덩어리)으로 나뉘어 캔버스에 그대로 올라가고, 그 위에 정본 부품을 이어서 놓으면 됩니다.

서버도 열쇠도 쓰지 않아서 **웹에 올린 주소에서도 됩니다.** 파일에서 온 화면은 그 브라우저 안에만 있고 저장소에는 남지 않습니다.
원본 칸은 레거시 모습 그대로 올라갑니다 — 정본 부품으로 바꿔치기하지 않습니다.

## 받은 파일 푸는 법 (저장소 쪽)

```bash
npm run screen:import
```

다운로드 폴더에서 가장 최근 것을 찾아 풉니다. 파일을 직접 주려면:

```bash
npm run screen:import -- ~/Downloads/s1-screens_....json --as 모두앱
```

결과는 `reports/screen-import/<이름>/` 아래에 이렇게 놓입니다.

- `<페이지>.md` — 화면 목록·많이 쓰인 부품 한눈표
- `raw/<페이지>.json` — 기계 판독 원자료
- `shots/*.png` — 화면 그림

## 무엇이 담기나

화면마다: 크기·자리·바탕색·자동배치(간격과 안쪽 여백)·쓰인 부품 목록, 그리고 **빌더가 바로 먹는 칸 목록**(위에서 아래로의 차례와 칸마다의 그림).
요소마다: 이름·종류·자리·크기·색·테두리·모서리·투명도, 글자는 내용과 글꼴·크기·굵기·줄간격·정렬,
그리고 **시안에 매여 있으면 디자인가이드 토큰/스타일 이름**까지.

그림만으로는 그대로 만들 수 없어서 숫자를 함께 싣는 것이 이 플러그인의 요점입니다.
레거시 화면처럼 토큰이 안 매인 시안은 토큰 이름 칸이 비어 오고, 그때는 색 값이 그대로 보입니다.
