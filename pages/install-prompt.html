3
AI에게 전달할 요청문
그대로 복사해서 붙여넣으세요

PC 화면을 구현해 주세요. design/DESIGN.core.md를 최우선 기준으로 사용하고, 시각값은 CSS 토큰 파일을 적용하세요. 동작은 registry/components/component-behavior.pc.json에 정의된 검증된 규칙만 구현하세요. 정의되지 않은 동작이나 상태는 임의로 만들지 마세요. 필요하면 pages/components.html의 실제 동작을 참고하세요.

지켜야 할 원칙
  1. 기존 컴포넌트와 정의된 변형을 먼저 재사용합니다.
  2. 색상이나 크기를 임의 값으로 복사하지 않고 Semantic 또는 Component 토큰을 사용합니다.
  3. PC 동작은 status: verified인 규칙만 구현합니다.
  4. not-defined는 자유롭게 만들어도 된다는 뜻이 아닙니다. 필요한 경우 디자인 시스템 담당자에게 확인합니다.
  5. 이 저장소는 현재 PC 기준입니다. 모바일 동작 계약은 포함하지 않습니다.
4

준비 중

개발자용 배포는 준비 중입니다

지금 공개하면 반쪽짜리 기준을 드리게 되어, 준비가 끝날 때까지 열지 않습니다.

왜 아직인가

색·간격 같은 토큰은 준비돼 있지만, 그것만으로는 버튼 하나를 만들 수 없습니다. 실제 컴포넌트 스타일은 아직 가져다 쓸 수 있는 파일로 정리되지 않았고, 그 값이 디자인 정본과 일치하는지도 확인이 끝나지 않았습니다. 검증되지 않은 값을 「S1 표준」으로 배포하면, 서비스마다 서로 다른 기준이 퍼집니다.

준비가 끝나면 여기서 받을 수 있습니다
  • 토큰 CSS — 색 · 간격 · 반경 · 글자, 다크모드 포함
  • 컴포넌트 CSS — 버튼 · 인풋 등 실제 스타일 (디자인 정본에서 자동 생성)
  • 컴포넌트 마크업 — 클래스 이름과 구조
  • PC 동작 규칙 — 클릭 · 선택 · 열고닫기 · 키보드 · 포커스
그동안에는

AI 코딩 도구(Claude Code · Cursor 등)를 쓰신다면 지금도 작업할 수 있습니다. AI 프롬프트 탭에서 디자인가이드 저장소를 받아 연결하세요.

S-1 S/W UX Guide 설치/검수기
업데이트 2026-07-21 10:43
Figma Desktop에서 실행하는 플러그인 — 토큰·텍스트 스타일·컴포넌트 세트를 파일에 설치하고, 선택한 프레임의 색·컴포넌트를 정본 기준으로 검수합니다
다운로드
① 토큰·컴포넌트 설치
Foundation·Semantic·Text Styles·Component Set을 골라 Figma 파일에 변수·텍스트 스타일·컴포넌트 세트로 설치합니다. Light/Dark 모드가 자동으로 연결됩니다.
② GUI 검수
선택한 프레임을 검수해 원본은 그대로 두고 "— 개선안" 복제본을 만듭니다. 정본으로 교체 가능한 요소는 컴포넌트 교체를, 그 외 직접 지정된 HEX 색은 유사 시멘틱 토큰을 제안합니다.
설치 방법 — 처음 등록할 때 펼쳐보세요
  1. 받은 ZIP을 압축 해제하면 s1-ux-design-guide-installer 폴더가 생깁니다 (안에 manifest.json · code.js · ui.html)
  2. 이 폴더를 영구적인 위치(예: 문서 폴더)로 옮겨 둡니다 — Figma가 이 경로를 참조합니다
  3. Figma Desktop App 상단 메뉴 Plugins → Development → Import plugin from manifest…
  4. 폴더 안의 manifest.json을 선택합니다
  5. 설치할 Figma 파일을 Figma Desktop App에서 엽니다
  6. Plugins → Development → S-1 S/W UX Guide 설치/검수기 클릭
  7. 패널에서 필요한 항목(Foundation · Semantic · Text Styles · Component Set)을 체크하고 [선택 항목 설치] 클릭
  8. 완료 후 왼쪽 패널 Local variables · Text styles · Assets에서 확인합니다
폴더를 옮기거나 삭제하지 마세요. Figma는 등록 시점의 폴더 경로를 참조하므로, 폴더가 사라지면 "manifest를 찾을 수 없음" 오류가 납니다. (Downloads 폴더는 자동 정리될 수 있어 권장하지 않습니다.)
