PC · Mobile Light · Dark Base Input · Button Toggle · Chip (신규) 검수본 2026-08-31 · 06 Password · Search는 다음 단계

직접 확인하는 방법

  1. Tab 키로 이동해 Button의 파란 포커스 테두리가 잘 보이는지 확인합니다.
  2. Button 위에 마우스를 올리고 눌러서 Hover·Pressed 반응을 확인합니다.
  3. Input에 직접 입력해 remove 아이콘이 나타나는지, 아이콘 위 Hover 배경과 누른 뒤 값 삭제·초점 복귀를 확인합니다.
  4. Checkbox·Radio는 상자만 있는 기본형과 라벨이 붙은 형태를 나란히 놓았습니다. 라벨을 눌러도 선택되는지, 라디오는 화살표 키로 옮겨지는지 확인합니다.
  5. Toggle은 눌러서 켜고 끄고, Tab·Space로도 바뀌는지 확인합니다. 비활성은 눌러도 바뀌지 않아야 합니다.
  6. Chip은 눌러서 선택하고 다시 눌러 해제되는지, Line·Solid의 선택 표시가 구분되는지 확인합니다.
  7. PC와 Mobile, Light와 Dark에서 같은 의미와 우선순위로 보이는지 비교합니다.
현재 초점: 없음 모든 상태는 실제 HTML 속성 또는 승인된 공개 상태를 사용합니다. 검수용 강제 상태는 사용하지 않았습니다.

1. Base Input

안내 문구는 선택 사항입니다. Editing에서는 값이 있을 때 remove 아이콘이 나타나며, PC에서는 아이콘 위에 마우스를 올리면 해당 누르는 영역에만 Hover 배경이 생깁니다. 비밀번호 보기/숨기기와 검색 실행은 다음 단계입니다.

2. Button

Primary·Secondary·Blue Line의 크기와 상태를 비교합니다. Hover·Pressed·Focus Visible은 실제 마우스와 키보드로 확인합니다.

3. Checkbox

정본 상태 5종을 그대로 옮겼습니다. 라벨은 선택 부품이라 없는 형태가 기본이고, 붙이면 라벨을 눌러도 선택됩니다. 부분선택(중간 상태)은 정본에 없어 이번 배포에 넣지 않았습니다.

4. Radio

정본 상태 5종 × 라벨 유무를 그대로 옮겼습니다. 같은 그룹은 하나만 선택되고, 그룹 안에서는 화살표 키로 이동합니다.

5. Toggle

정본 4가지(켜짐·꺼짐 × 기본·비활성)를 그대로 옮겼습니다. 정본에 마우스오버 변형과 움직임(애니메이션)이 없어 웹에도 넣지 않았습니다. 크기 축이 없어 40×20 고정입니다.

6. Chip

Line·Solid × 상태 4종입니다. 크기는 정본에 있는 조합만 만들었습니다 — PC는 SM 28px·MD 34px, Mobile은 SM 30px. 필터 칩(드롭다운·완료 상태)과 아이콘·닫기(X)는 이번 범위가 아닙니다.

배포 모듈 확인 중… 후속 범위: Filter Chip → Password Field → Search Input. 정본과 Registry가 준비된 뒤 같은 방식으로 이 화면에 추가합니다.
