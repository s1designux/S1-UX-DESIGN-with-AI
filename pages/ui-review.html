UI LIBRARY · CANDIDATE REVIEW

Base Input · Button 실제 배포본 검수

이 화면과 퍼블리셔·개발자가 받는 파일은 같은 ui-library/dist를 사용합니다. 아래 UI를 직접 누르고 입력하면서 모양과 사용성을 확인해 주세요.

PC · Mobile Light · Dark Base Input · Button Password · Search는 다음 단계

직접 확인하는 방법

  1. Tab 키로 이동해 Button의 파란 포커스 테두리가 잘 보이는지 확인합니다.
  2. Button 위에 마우스를 올리고 눌러서 Hover·Pressed 반응을 확인합니다.
  3. Input에 직접 입력하고, Error·Correct·Read-only·Disabled 차이가 분명한지 확인합니다.
  4. PC와 Mobile, Light와 Dark에서 같은 의미와 우선순위로 보이는지 비교합니다.
현재 초점: 없음 모든 상태는 실제 HTML 속성 또는 승인된 공개 상태를 사용합니다. 검수용 강제 상태는 사용하지 않았습니다.

1. Base Input

라벨·입력 영역·안내 문구로 구성된 기본 입력창입니다. 비밀번호 보기/숨기기와 검색 지우기 동작은 이번 파일럿에 포함하지 않습니다.

2. Button

Primary·Secondary·Blue Line의 크기와 상태를 비교합니다. Hover·Pressed·Focus Visible은 실제 마우스와 키보드로 확인합니다.

배포 모듈 확인 중… 후속 범위: Password Field → Search Input. 정본과 Registry가 준비된 뒤 같은 방식으로 이 화면에 추가합니다.
